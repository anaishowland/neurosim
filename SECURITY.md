## Security Policy

### Supported versions
- We support security fixes for the latest released version of `neurosim` only.

### Reporting a vulnerability
- Do not open public GitHub issues for security-related matters.
- Preferred: open a private GitHub Security Advisory for `ParadigmShift-AI-Corp/neurosim`.
- Alternatively, open an issue on GitHub

Please include:
- A clear description and impact
- Steps to reproduce or a proof of concept
- Affected component(s) or file(s) if known

### Our process
- Acknowledgement: within 2 business days
- Triage and initial assessment: within 5 business days
- Remediation: timeline depends on severity and complexity
- Coordinated disclosure: we appreciate responsible disclosure and will credit reporters (with permission)

### Scope
This policy applies to the code in this repository. For vulnerabilities in third-party dependencies, we will coordinate with upstream projects where appropriate.
